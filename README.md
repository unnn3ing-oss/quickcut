# QuickCut（網頁版影片剪輯）

在瀏覽器裡直接剪影片的多軌時間軸工具：把影片、音訊、圖片排成一支影片，匯出 MP4／MOV／WebM。版面是左側媒體庫、中間檢視器、右側詳細內容，下方是時間軸，操作邏輯以 DaVinci Resolve 的 Edit 頁為準。

- **網址**：<https://unnn3ing-oss.github.io/quickcut/>
- 素材全部在本機瀏覽器處理，**不會上傳**到任何伺服器。
- 建議用最新版 **Chrome 或 Edge**（匯出用 WebCodecs）；桌面瀏覽器專用。
- 從 [QuickPatterntool](https://github.com/unnn3ing-oss/QuickPatterntool)（圖片套版產生器）的「剪輯」分頁獨立出來。

## 使用說明

### 簡易模式與專業模式（4.00）

頁首右上的「**簡易｜專業**」切換介面。第一次打開是**簡易模式**，適合第一次剪片；要多軌剪輯、關鍵影格、EQ 等完整功能就切到**專業模式**。選擇會記住。兩種模式用的是**同一份專案**，隨時切換都不會少任何東西（簡易模式只是把介面變簡單）。

| | 簡易模式 | 專業模式 |
|---|---|---|
| 工具列 | 一排大按鈕：加素材、分割、刪除、復原、重做、加字幕、加音樂、對拍子、**一鍵成片** | 完整工具列（工具、編輯方式、變速、節拍…） |
| 加進來的素材 | 自動依序排到時間軸結尾 | 留在媒體庫，自己放上時間軸 |
| 點選片段後右側 | 「快速調整」（點選項就套用） | 詳細內容（所有數值） |
| 軌道名稱 | 影片、畫中畫、原聲、音樂 | V1、V2、A1、A2 |
| 軌道標頭按鈕（鎖定、眼睛、M、S） | 隱藏 | 顯示 |

**開始畫面**：打開空專案時會先問「想做什麼影片？」：
- **直式短影音**（最常用）：9:16、1080×1920，適合 Reels、Shorts、抖音；橫的素材自動加模糊背景。
- **橫式影片**：16:9、1920×1080，適合 YouTube、簡報影片。
- **自己來**：輸出比例依第一支素材，直接進專業模式。
- 也可以直接把檔案拖進開始畫面（用直式短影音開始並匯入），或按「開啟舊專案…」；按 Esc 等於選直式短影音。勾「下次不要再顯示」就不會再出現。

**第一次使用的教學**：選了直式或橫式後，會有三個小泡泡依序指出「加素材」、時間軸、右側面板怎麼用；按「略過教學」或看完後就不再出現。

**簡易模式的工具列**：
- **加素材**：選影片、照片或音樂（也可以直接拖進畫面）。影片、照片依序接在「影片」軌最後面（影片的聲音放「原聲」軌），音樂放到「音樂」軌（沒有就自動新增）。比例和輸出不同的素材自動用模糊背景；加完會選取第一段新片段。整批加入只算一步，按一次「復原」就能拿掉。
- **分割**：在播放頭（紅線）把片段切成兩段（Ctrl／⌘＋B）。
- **刪除**：刪除選取的片段，後面的自動往前補，不留空隙。
- **加字幕**：在播放頭加一段字幕。**加音樂**：選一首音樂放到「音樂」軌。**對拍子**：打開節拍偵測與卡點（見下方「節拍與卡點」）。
- **一鍵成片**：工具列最右邊的大按鈕，選素材、音樂和風格，自動排好整支影片（見下方「一鍵成片」）。
- 快捷鍵和專業模式一樣可以用。

**快速調整**：在簡易模式點時間軸上的影片、圖片或音訊片段，右側會換成「快速調整」，點選項馬上套用，每次改動都是一步復原。多選時一起套用到所有選取的片段。

| 項目 | 選項 | 說明 |
|---|---|---|
| 畫面 | 模糊背景／填滿畫面／完整顯示 | 素材比例和輸出不同時怎麼放 |
| 動態 | 不動／慢慢放大／慢慢縮小／向左平移／向右平移 | 從片段開頭到結尾自動加好關鍵影格 |
| 接下一段 | 直接切／淡化／推移／閃白／縮放 | 這段接到下一段的轉場 |
| 速度 | 正常／慢動作（0.5×）／子彈時間／快轉 2× | 長度跟著變，後面的片段一起推拉 |
| 音量（原聲音量） | 0%～200% | 0% 是靜音 |
| 濾鏡 | 原色／暖陽／冷調／黑白 | 見下方「濾鏡」 |

要調更細的數值（位置、裁切、關鍵影格、EQ…）就按面板最下面的「**切到專業模式**」，專案內容完全一樣。

**濾鏡**：原色、暖陽、冷調、黑白四種。簡易模式在快速調整裡選；專業模式在「詳細內容 → 變形」的「**濾鏡**」選，並可用「**濾鏡強度**」（0～100%）調整濃淡。模糊背景也會套用同樣的濾鏡，預覽和匯出的顏色一樣。

### 一鍵成片（4.10）

簡易模式工具列最右邊的「**一鍵成片**」：選好素材和音樂、挑一個風格，自動排好整支影片、對好拍子、加上動態和轉場。產生的都是一般的片段、轉場和關鍵影格，之後在時間軸上照常修改（切到專業模式也一樣）。

1. **選素材**：列出媒體庫裡所有的影片和照片，預設全選。點一下選取／取消，縮圖上的**號碼是播放順序**（取消後再點會排到最後）。按「＋加素材」可以在對話框裡直接匯入，這時素材**不會**先排到時間軸，等按「產生影片」才排。
2. **選音樂**：媒體庫裡的音樂排前面，有聲音的影片也可以拿它的聲音當配樂；或選「**不要音樂**」。按「加音樂…」可以直接匯入一首。
3. **風格**：

| 風格 | 換段節奏（有音樂／沒音樂） | 動態 | 轉場 | 其他 |
|---|---|---|---|---|
| 節奏感 | 每 2 拍／每段 1.2 秒 | 慢慢放大、慢慢縮小交替 | 每隔一個剪接點閃白 | — |
| 溫柔回憶 | 每 4 拍（約一小節）／每段 3 秒 | 放大、左移、縮小、右移輪流 | 每個剪接點淡化 | 暖陽濾鏡 50%；開頭從黑淡入、結尾淡出到黑（0.5 秒） |
| 電影感 | 每 4 拍（約一小節）／每段 3.5 秒 | 慢慢放大 | 每個剪接點浸入黑色 | 冷調濾鏡 40%；開頭結尾淡入淡出（1 秒）；整支影片加上 2.39：1 **電影黑邊** |

按「**產生影片**」後：
- **有音樂**：先分析音樂的節拍（幾秒鐘），每一段都在拍子上切換。素材少、歌比較長時，每段會自動拉長成風格拍數的倍數（最多 8 拍），盡量配滿整首歌。音樂放在「音樂」軌（沒有就自動新增），從影片開頭放到影片結尾（音樂比較短就放完為止），最後 1.5 秒淡出；這時**影片的原聲不放**。音樂抓不到明顯的節拍時，改用固定長度。
- **沒有音樂**：每段固定長度，影片的原聲放在「原聲」軌。
- **影片取中段**：影片比一段長時取中間那一段；比一段短就整段用，後面的段落接著排。照片每段長度照節奏。
- 比例和輸出不同的素材自動加**模糊背景**；片段太短放不下的地方不加轉場。
- 會**接在時間軸目前內容的後面**，不會蓋掉已經剪好的東西。整批只算一步，不滿意按一次「**復原**」就全部拿掉。
- 用到的軌道（影片、原聲或音樂）鎖定時不能產生。

### 專業模式

以下是專業模式的完整說明（簡易模式也能用快捷鍵和大部分功能）。

**說明與頁首**：頁首的「**說明**」（或按 **?**）會打開使用說明：基本流程、分類好的快捷鍵與小提醒。視窗比較窄時，「開啟專案／儲存專案／說明／深色」會收進「**⋯**」選單，「匯出影片」一直顯示。筆電這類比較矮的螢幕（1366×768、1280×720、1024×700）會自動縮小頁首與留白，整頁不用捲動。

**儲存與開啟專案**：
- 頁首的「**儲存專案**」（Ctrl／⌘＋S）會下載一個 `.qcut` 專案檔，只存剪輯資料（時間軸、片段、字幕、轉場、各種調整）和每個素材的檔名、大小，**不含影片本身，所以只有幾 KB**。
- 「**開啟專案**」（Ctrl／⌘＋O，或直接把 `.qcut` 拖進畫面）會還原剪輯進度。缺少的素材會列在媒體庫上方，時間軸上的片段暫時變灰並標示「缺少素材」，接回來就恢復。接回素材的方式：
  - **允許存取並重新連結**：在同一台電腦、同一個瀏覽器（Chrome／Edge）匯入過的素材，瀏覽器會記住檔案位置，按一次就全部接回（有時瀏覽器會自動允許，連按都不用）。
  - **選擇資料夾**：選素材所在的資料夾，依「檔名＋大小」自動配對，子資料夾也會找（Chrome／Edge）。
  - **選擇檔案…**或**直接拖進來**：檔名一樣的會自動配對（不分大小寫）；長度和存檔時不同會提醒。
  - 開專案前已經在媒體庫裡的素材，檔名對得上就直接沿用。
- 還有素材沒接回時，匯出會先提醒，不會匯出黑畫面。
- **自動暫存**：每次改動後約 1.5 秒自動存在瀏覽器裡（也只有剪輯資料）。不小心重新整理或關掉分頁，下次打開會問「還原上次的剪輯？」：選「還原」再接回素材就能繼續；選「開新專案」會清掉暫存。

**外觀與版面**：預設**深色**（DaVinci 風格的深灰），頁首右上的「深色」開關可切到淺色，選擇會記住；工具列只有一排，放不下時可左右捲動（滑鼠滾輪也行），復原／重做在最右側；檢視器上方的「直式版面」按鈕可以把預覽放到整頁左側、從頂端延伸到時間軸底部，畫面更大（按鈕一直都在；直式專案預設開啟、橫式預設關閉，兩種各自記住）；上排各欄之間的分隔條可以左右拖曳調整欄寬（一般版面調媒體庫／詳細內容，直式版面調預覽欄／媒體庫），雙擊分隔條恢復預設，寬度會記住；媒體庫可以切換「列表」或「網格」（大縮圖）顯示，選擇會記住。

**匯入素材**：在媒體庫匯入影片、音訊或圖片。匯入時會讀取長度與尺寸，並產生縮圖條與波形；大檔不整個讀成 base64，無法讀取的檔案會列出原因。第一支影片的 fps 決定專案的 fps（24／25／30／50／60），之後固定。

**放上時間軸**：在來源檢視器用 I、O 設定入點與出點，再選一種方式放上時間軸（工具列也有對應按鈕，筆電的 F 鍵被系統佔用時可以用按鈕）：

| 方式 | 快捷鍵 | 行為 |
|---|---|---|
| 插入 | F9 | 在編輯點插入，後面的片段往後推 |
| 覆蓋 | F10 | 蓋在編輯點上，不推後面的片段 |
| 替換 | F11 | 以播放頭對齊來源的播放頭，長度與目標片段相同 |
| 加到結尾 | F12 | 接在時間軸最後面 |

時間軸上的入點／出點優先於播放頭。影片有聲音時，影像與聲音會一起放上並自動連結（連結選取開關見下方快捷鍵）。

**工具**（A、B、T 切換，或點工具列）：

- **選取**：選取與移動片段。點時間軸上沒有片段的空白處會取消選取（播放頭不動；要移動播放頭請點時間尺或拖紅色箭頭）。從空白處（軌道上沒片段的地方，或軌道下方）按住拖曳可以**框選**多個片段；拖到時間軸左右邊緣會自動捲動，框會跟著延伸，捲進來的片段也選得到。移動到別的片段上時，被蓋到的部分會被覆蓋掉（同 DaVinci）。
- **選取整條軌**：點時間軸左側的**軌道標頭**（名稱或空白處；鎖定／眼睛／M／S 按鈕除外）會選取這條軌上的**所有片段**，同時設為目的軌道；右側詳細內容會出現對應的調整項目（影片：變形、裁切、速度…；音訊：增益、淡入淡出、EQ…；字幕：文字、外觀、動畫…），標題寫出「已選取 N 個片段」，改數值會**一起套用到整條軌**，一次 Ctrl+Z 就能還原。按住 Shift 或 Ctrl（Mac 是 ⌘）點其他軌道標頭可以加選，再點一次取消；右鍵選單也有「選取這條軌的所有片段」。只選這條軌，不會連帶選到連結的影像或聲音。
- **刀片**：在滑鼠位置切開片段；Ctrl／⌘＋B 則在播放頭切開。
- **修剪**：依滑鼠位置自動變成不同的修剪：
  - 靠近兩段交界的邊緣：**滾動**（兩段一起改，總長不變）。
  - 靠近沒有鄰居的邊緣：**波紋**（改長度，後面未鎖定軌道的片段跟著移動）。
  - 片段中間的上半部：**滑移**（只換來源的位置，長度不變）。
  - 片段中間的下半部：**滑動**（前後鄰居一長一短，這段位置不變）。

**特效與字幕**：左上的「**特效**」分頁（原本叫「轉場」）分成「轉場特效」和「字體特效」兩區。轉場特效有 19 種轉場：基本的交叉疊化、淡出到黑、擦除、推移等，以及 3.20 新增的甩鏡、閃光、故障、縮放衝刺、旋轉、光漏、百葉窗、馬賽克、卡片翻轉、立方體、對開門。滑鼠移到縮圖上會播放轉場動畫。選好片段後按「**加到開頭**」或「**加到結尾**」，或直接把轉場拖到片段的開頭或結尾。

- 兩段相接的地方是**雙邊轉場**（兩段互相過場）；沒有相鄰片段的開頭是**開頭淡入**，結尾是**結尾淡出**（和背景或黑畫面過場）。
- 轉場附在片段的邊緣上（同 DaVinci）：把相接的兩段拉開時，轉場留在沒被移動的那一段，變成單邊；再接回去會自動變回雙邊。刪除片段只會刪掉附在它上面的轉場。
- **方向與顏色**：甩鏡、擦除、推移、滑動、百葉窗、卡片翻轉、立方體可選上下左右；旋轉可選逆時針／順時針；對開門可選左右或上下打開。閃光、光漏、浸入顏色可以自選顏色（閃光預設白光，改成黑色就是「閃黑」）。
- 新轉場用顯示卡（WebGL）畫；瀏覽器不支援時會自動改用交叉疊化。
- 時間軸上的轉場方塊可以點選後在詳細內容調整、拖把手改長度、按 Delete 刪除；方塊只佔片段下半部，上半部的邊緣仍可修剪。
- **轉場時的聲音**：兩段影片都有連結的聲音、而且聲音在同一條音訊軌上相接時，轉場範圍內會自動做等功率的**交叉淡化**（時間軸上會畫出交叉曲線）。來源前後沒有多餘的素材時，淡化會縮短。單邊轉場則讓聲音跟著淡入或淡出。和手動設定的淡入淡出會疊加。

**字體特效**：讓字幕出現時有動畫，有「彈出」「逐行彈出」「逐字彈出」「下往上跳起」「逐行跳起」「逐字跳起」（整塊／一行一行／一個字一個字），選「無」可以移除。選取字幕片段後按「套用到選取的字幕」，或直接把特效拖到時間軸的字幕片段上；長度（預設 0.5 秒）在詳細內容的「動畫」分頁調整。滑鼠移到縮圖上會播放效果。

**字幕**分頁分成三區：
- **字幕清單**：做整支影片的對白字幕。
  - **匯入 SRT**：按「匯入 SRT」或直接把 `.srt` 檔拖進畫面，每一段會變成「字幕」軌上的一個字幕片段（UTF-8、Big5 都可以）。
  - **匯出 SRT**：按「匯出 SRT」（字幕分頁或右側「清單」分頁）把「字幕」軌的字幕存成 `字幕_日期時間.srt`（UTF-8）。沒有字幕清單時，改匯出時間軸上所有有文字的字幕；選字變色的星號會拿掉、空白的段落略過。
  - **V 標記**：在字幕分頁（或選取字幕時），播放控制列右側會出現「**V**」。邊播放邊按 V（或點它），就在播放頭加一段字幕，右側詳細內容的「**清單**」分頁會多一行文字框，可以一行一行輸入（Enter 跳下一行，Shift＋Enter 換行，Esc 離開）。
  - **長度規則**：每段預設 **10 秒**；碰到下一段就提早結束，結束在下一段開始的**前一格**（−1 frame）。在前一段還在播的時候按 V，前一段也會改成在這一格的前一格結束。匯入 SRT 時互相重疊的段落也照這個規則處理。
  - 時間軸上的字幕片段直接顯示字幕內容；點清單裡的時間可以跳到那一段，按 × 刪除。
- **字幕過場**：原本的 6 種動畫預設（靜態、淡入淡出、打字機、下三分之一條、捲動、跑馬燈）。
- **字幕樣式**：一鍵套用外觀（顏色、描邊、外框、陰影、立體、斜體、強調色），不動文字、字型、位置和過場。有「基本」「藍白漸層」「紫色立體」「黑邊青框」「黑邊強調紅」。用法同字體特效（按鈕或拖到字幕片段上）；新增的字幕也會用目前選取的樣式。

**詳細內容分頁**：右側詳細內容依時間軸上點選的物件分成幾個分頁，一次只看一頁，各種物件會記住上次看的分頁：
- 字幕清單的字幕：多一個 **清單** 分頁（所有字幕一行一行列出，放在最前面）。
- 字幕：**文字**（內容、選字變色、字型、字級、位置）｜**外觀**（顏色、描邊、外框、漸層、斜體、立體、陰影、背景）｜**動畫**（字幕過場、字體特效）｜**變形**（含裁切）｜**資訊**
- 影片／圖片：**變形**｜**裁切**｜**音訊**｜**速度**｜**資訊**（沒有的項目不會出現，例如純音訊只有音訊／速度／資訊）
- 轉場、沒選任何東西時不分頁。

**選字變色**：在「文字」分頁，文字會拆成一格一格，點字（或按住拖過一串）就會變成「變色顏色」，再點一次取消；也可以直接在文字裡用 `*星號*` 包住，例如 `進行*瘋狂*的編輯`。

**外框（色框）與文字效果**：在「外觀」分頁可以：
- 按「＋ 增加外框」在描邊外面一圈一圈加色框（最多 4 層，各自調顏色與粗細，可以個別移除）。
- 開「漸層」讓文字上下兩色；調「斜體」角度；調「立體深度／顏色／方向」做立體字。

字幕過場有 6 種動畫預設，字級以短邊 1080 像素為基準，輸出尺寸不同時會等比縮放。字型可選「粗體（預設）」、「仙人掌明體」（Cactus Classical Serif，明體／宋體風格）與「系統黑體」；仙人掌明體是完整字集（約 5.8 萬字，含罕用字），檔案約 10 MB，第一次選用時才下載（之後瀏覽器會快取）。

**在預覽上直接調整素材**：時間軸模式下，點時間軸上的片段（或直接在預覽上點畫面裡的素材，重疊時選最上層），預覽上會出現控制框（字幕是黃色、其他素材是藍色）：拖本體移動位置、拖四個角等比縮放、拖上方圓點旋轉（按住 Shift 每 15° 一格）。拖到畫面中線附近會自動吸附到正中，按住 Alt 不吸附；拖曳中按 Esc 取消。整次拖曳只算一步復原。字幕拖曳改的是字幕的「水平／垂直位置」，其他素材改的是變形的「位置」。

**詳細內容的拉桿**：變形的縮放 X／Y、位置 X／Y，以及字幕的水平／垂直位置都有拉桿，後面保留可以直接輸入數值的框（輸入框可以超出拉桿範圍）；雙擊拉桿恢復預設值。

**安全框**：輸出比例是 9:16 時，檢視器上方會出現「安全框」按鈕。開啟後在預覽上疊一層 Reels／短影音的介面示意（右側愛心、留言、轉發、分享按鈕，下方帳號、說明文字與導覽列；帳號、文字與數字都以灰條代替），會被介面蓋住的範圍顯示成灰色，方便把字幕與重點放在安全範圍內。只在預覽顯示，不會匯出；選擇會記住。

**音訊**：每段音訊可調增益（dB）、左右聲道（Pan）、淡入淡出（可調曲線），以及 6 段 EQ（附頻率響應圖）。軌道可靜音、獨奏、鎖定、隱藏。

**變速、倒播、定格**：Ctrl／⌘＋R 開變速、Shift＋R 開定格對話框、倒播可在速度設定中切換。變速會**同時改變音高**（目前沒有保留音高的選項）。

**曲線變速（Speed Ramp）**：在變速對話框（Ctrl／⌘＋R）的「曲線變速」選一種，速度會在片段裡**平滑地**變快變慢：
- **中段慢動作**（前後正常、中間 30%）、**子彈時間**（快 → 極慢 → 快）、**漸漸加速**、**漸漸減速**、**快速切入**、**快速切出**，每個按鈕上都有速度曲線的小圖（虛線是 100%）。
- **強度**：10%～100%，越低起伏越小。**基準速度**：曲線裡的百分比都是相對它，例如基準 200% 時中段慢動作是 60%。
- 建議勾選**波紋**：用到的畫面不變，片段長度跟著變（慢動作會變長，後面的片段一起往後推）。不勾時片段長度不變、改用的畫面長短，素材不夠時會提醒。
- 連結的聲音一起變速（音高跟著變），預覽和匯出一樣。切開、修剪後每一格的畫面都不變。時間軸片段上會顯示「曲線」。
- 要取消就選「**不用曲線**」再套用。曲線變速的片段不能倒播（要倒播先取消曲線）。

**輸出比例**：依來源（第一支影片的尺寸，長邊上限 3840）、9:16（1080×1920）、16:9（1920×1080）4:5（1080×1350）、1:1 方形（1080×1080）或 **3:2 Open Gate**（1620×1080，相機用整片感光元件錄的畫幅）。
- **換比例時一鍵套用**：換了輸出比例後，如果時間軸上有素材的比例和新畫面不同（例如橫式影片放進 9:16），會跳出小視窗讓你選「**模糊背景**」（推薦）、「**填滿裁切**」或「保持黑邊」，一次套用到所有影片和圖片片段（鎖定的軌道不改），按一次 Ctrl／⌘＋Z 就能復原。
- **模糊背景**：片段完整顯示，上下（或左右）的空白用同一個畫面放大、模糊、稍微壓暗補滿，是短影音最常見的做法。也可以在「詳細內容 → 變形 → 畫面符合」逐段選「符合＋模糊背景」，並用「背景模糊」調整模糊程度。背景永遠蓋滿畫面，不跟著片段的縮放、位置移動。

**電影黑邊**：沒選任何片段時，「詳細內容 → 專案」的「**電影黑邊**」可以選不加、2.39：1（寬銀幕）、2：1、1.85：1、**Open Gate（3:2）**，做出電影的感覺（不用自己加色塊）。畫面比選的比例「高」就上下加黑邊，比較「寬」就左右加——例如 16:9 專案選 Open Gate 是左右黑邊，9:16 選 2.39 是上下黑邊。
- 黑邊蓋在所有影片、照片、色塊上面，但在**字幕下面**：字幕放進黑邊裡也看得清楚（這是電影上字幕的常見做法）。
- 直式（9:16）影片一樣是上下加黑邊，中間留下 2.39：1 的寬銀幕畫面。畫面本來就比選的比例更寬時不加。
- 預覽和匯出完全一樣；一鍵成片選「電影感」會自動加 2.39：1，按一次復原就連同整批片段一起拿掉。

**關鍵影格（動畫）**：在「詳細內容 → 變形」（或「裁切」）每個數值右邊都有一個 **◇**：
- 按 ◇ 在播放頭加關鍵影格；之後只要移動播放頭、改數值（輸入、拉桿、或在預覽畫面上直接拖曳／縮放／旋轉），就會自動在播放頭加（或修改）關鍵影格，中間自動補間。
- ◇ 空心＝沒有動畫、半實心＝有動畫但這一格沒有關鍵影格、實心＝這一格有（再按一次刪掉）。數值會顯示播放頭那一格的樣子。
- 上方的工具列可以跳到上一個／下一個關鍵影格、選這一格到下一格的走法（**等速**、**緩入緩出**、**停格**），或清除全部；時間軸片段下緣的小黃菱形是關鍵影格的位置。
- **一鍵動畫**：「慢慢放大」「慢慢縮小」「向左平移」「向右平移」，從片段開頭到結尾自動加好（緩入緩出）。多選時一次套到所有選取的片段，很適合照片輪播。
- 可以做動畫的參數：縮放、位置、旋轉、錨點、不透明度、裁切（上下左右）。修剪、切開、變速時動畫會跟著畫面走。「重設變形」「重設裁切」也會清掉對應的關鍵影格。

**節拍與卡點**：工具列的「**節拍**」：
- **① 自動偵測**：分析音訊軌上的音樂（或選取的有聲片段），在每一拍加上黃色的「節拍」標記；可選每半拍、每一拍、每 2 拍或每小節。節奏清楚的音樂比較準；很快的歌可能被抓成一半的速度，這時選「每半拍」。
- **② 手動打拍子**：按「開始打拍子」會從音樂開頭播放，跟著音樂按 **M**，每按一下加一個節拍標記；按空白鍵停止。
- **③ 卡點**：在時間軸選取要卡點的圖片或影片，選「每 1／2／4 拍換一段」後按「套用」，片段會依時間順序排到節拍上（第一段的開頭不動）。影片不夠長時用到最長、後面留空隙；連結的聲音跟著移，後面沒選到的片段一起推拉。
- 節拍標記就是一般的時間軸標記，吸附也會對齊它們；「清除節拍標記」只會清掉名稱是「節拍」的標記。

**匯出影片**：按頁首「儲存專案」右邊的「**匯出影片**」，會打開全畫面的匯出面板：
- **快速匯出**（左側）：一鍵帶入社群平台的建議設定，都是 H.264＋AAC＋MP4：

  | 平台 | 尺寸 | 影像位元率 | 聲音 |
  |---|---|---|---|
  | YouTube 1080p／Shorts | 短邊 1080（Shorts 為 1080×1920） | 8 Mbps（30 fps 以下）／12 Mbps（48～60 fps），關鍵格每 0.5 秒 | AAC 384 kbps |
  | YouTube 4K | 短邊 2160 | 40／60 Mbps | AAC 384 kbps |
  | Instagram Reels／貼文 | 1080×1920（9:16）／1080×1350（4:5） | 5 Mbps | AAC 192 kbps |
  | Facebook 影片／Reels | 1080p／1080×1920 | 8 Mbps | AAC 192 kbps |

  平台建議的比例和專案不同時會提醒，並可以一鍵把專案改成建議比例；影格率依專案設定（Instagram 建議 30 fps 以下，專案超過時會提醒）。數字依 YouTube 官方上傳建議與 Meta／Instagram 常見規格整理，平台收到後都會再壓縮一次。
- **設定**（右側）：範圍（整段／In～Out）、**尺寸**（依專案，或 2160p／1440p／1080p／720p／480p，保持專案比例）、**畫質**（高／中／小依尺寸自動算位元率，或「自訂」直接輸入 Mbps）、**封裝格式**（MP4／MOV／WebM）、**影像編碼**（自動／H.264／VP9／AV1）、**聲音**（自動／AAC／Opus／不含聲音）與聲音位元率。
- 封裝格式能放的編碼：**MP4** 都可以；**MOV** 只放 H.264＋AAC（Apple／剪輯軟體相容）；**WebM** 只放 VP9／AV1＋Opus。這個瀏覽器不支援、或這個格式放不下的選項會停用並寫原因；指定的編碼不能用時會自動改用別的並說明。
- 下方即時顯示輸出尺寸、實際會用的編碼、位元率與預估檔案大小。設定會記住，下次打開還是一樣；選了平台後再改任何一項就變回「自訂」。
- **直接寫入硬碟**（Chrome／Edge，預設開啟）：按「匯出」會先問要存在哪裡，之後邊編碼邊寫入，整支影片不會放在記憶體裡，長片、4K 也不怕記憶體不足。取消時會丟掉寫了一半的檔案。關掉這個選項（或用 Firefox／Safari）就是匯出完成後從瀏覽器下載。
- 一般 Chrome／Edge 有 H.264＋AAC；Linux 版 Chromium 等沒有的瀏覽器會改用 VP9＋Opus（MOV 不能用）。

**修剪時間碼**：拖片段的開頭或尾端修剪時，拖的那一側邊緣旁會顯示目前拉到的時間碼（拖開頭顯示在左側、是第一格；拖尾端顯示在右側、是最後一格；滾動修剪顯示在剪接點、是前一段的最後一格），放開就消失。

**多選一起修剪**：先選好多段（Shift／Ctrl 點選或框選），再拖其中一段的邊緣，所有選取的片段會一起加長或縮短同樣的格數。選取工具（A）不推動其他片段（相鄰的片段延長會被擋住）；修剪工具（T）是波紋修剪，後面的片段會跟著推拉、不留空隙。

**目前限制**：

- 變速會改變音高。
- 很短的片段同時有開頭淡入與結尾淡出、而且兩者範圍重疊時，畫面只會套用其中一個。
- 沒有開「直接寫入硬碟」（或瀏覽器不支援）時，匯出的影片會先在記憶體中組好再下載，很長的 4K 影片會吃掉大量記憶體。
- 專案檔不含素材：換電腦時素材要自己帶過去（放在同一個資料夾最方便，選資料夾就能一次接回）。「允許存取」一鍵接回只限同一台電腦、同一個瀏覽器（Chrome／Edge）。
- 自動暫存存在這個瀏覽器裡，清除網站資料或用無痕視窗時不會保留；重要的進度請用「儲存專案」下載。
- 桌面瀏覽器專用，手機上不支援。
- 曲線變速目前只有 6 種預設曲線，還不能自己畫曲線。
- 之後才會加入：音量關鍵影格、影像穩定。

## 本地開發

- 直接用瀏覽器開 `index.html` 就能用，沒有建置步驟、沒有外部相依套件。
- 單元測試：`node --test test/*.test.js`
- 瀏覽器流程測試（需要 Playwright＋Chromium，素材會用 `ffmpeg` 自動產生）：
  `node test/edit-ui.e2e.js`、`node test/edit-render.e2e.js`、`node test/edit-export.e2e.js`、`node test/edit-fx.e2e.js`、`node test/edit-project.e2e.js`、`node test/ux.e2e.js`、`node test/edit-simple.e2e.js`、`node test/edit-auto.e2e.js`（每個 PR 也會由 GitHub Actions 自動跑）
- 4.00 起預設是簡易模式、空專案會跳開始畫面；既有的瀏覽器流程測試用 `test/e2e-pro.js` 固定成專業模式並略過開始畫面與教學，簡易模式由 `edit-simple.e2e.js` 測，一鍵成片由 `edit-auto.e2e.js` 測。

## 版本編號規則

版本號寫在 `changelog.json`，格式 `主版本.兩位數`（例如 `1.00`）。每次併入 `main` 前依下表升版，並在 `changelog.json` 新增一筆（繁體中文）：`"1.01": { "summary": "一行簡述", "items": ["…"] }`。

| 這次改了什麼 | 遞增 | 例 |
|---|---|---|
| 更改功能或介面（大改版、新增主要功能） | 主版本 +1，後兩位歸零 | `1.24` → `2.00` |
| 部分小功能 | 十位數 +1，個位歸零 | `1.24` → `1.30` |
| 介面完善、小 BUG | 個位數 +1 | `1.24` → `1.25` |

混合類型取最大的；數字照一般進位（`1.29` → `1.30`）。只改文件（`README.md`、`DESIGN.md`、`CLAUDE.md`）或測試時不升版。
